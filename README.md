# 哈兰历史地图 · Anbennar Timeline

在地图上浏览哈兰1444—1820年的局势变化，查阅相关事件、国家沿革与研究资料，并一起补充和修正这份社区地图。

**[打开在线地图](https://shen-hhao.github.io/anbennar-timeline/)**

> **阅读前请注意：历史重建中有许多年代、边界和政权变化属于根据资料作出的推测，不一定是官方正史。** 本项目不代表官方结论。**资料库仍不完善**，各国家、地区的收录深度不同，资料可能缺漏、冲突或更新滞后；地图上的颜色和年份不能单独当作确证，请结合对应来源、版本与不确定性说明阅读。

## 网页可以做什么

- **切年看地图**：在1444—1820年间切换，拖动、缩放地图，保持视角比较不同阶段的局势。
- **查看国家与宗属**：点击或搜索国家，查看已收录的领土与宗属信息，在“国家配色”和“宗主关系”视图间切换。
- **浏览事件与沿革**：按年份查看事件，打开国家沿革，了解已收录的变化及其日期限定。
- **查阅资料与推演依据**：进入资料库、来源和连续推演页面，查看已有记录、摘录、来源定位与方案解释；不是每条资料都附有可下载的完整原件。
- **反馈与共同完善**：通过 [Issues](https://github.com/shen-hhao/anbennar-timeline/issues) 报错、补来源或建议译名。不知道准确年份或省份ID，也可以描述位置和问题。

## 两个分支各做什么

| 分支 | 内容 | 更新后的效果 |
| --- | --- | --- |
| `main` | 经公开审查的 `dist/`、指南、提案、启动与检查脚本、相关测试 | 保存可审查的候选；提交或合并不会直接更新网站 |
| `gh-pages` | 已核验的 `dist/` **内部内容**放在分支根目录，另加 `.nojekyll` | 明确推送该分支后，由 GitHub Pages 发布这一静态快照 |

`main` 的示意布局：

```text
dist/                         网站代码、可公开数据与静态资源
docs/                         方法、来源范围、反馈与公开说明
changes/                      尚未采用的人工审查提案
scripts/                      本机启动与基础检查
tests/                        本次公开副本可运行的测试
README.md
CONTRIBUTING.md
AGENTS.md
package.json
```

`gh-pages` 根目录应能直接找到 `index.html`、`app.js`、`data/` 等站点内容及 `.nojekyll`，不要再套一层 `dist/`。指南、测试、研究数据库和原件不随站点发布。

本方案**不提交 `.github/workflows/`，不配置自定义 Actions、自动检查或自动部署工作流**。Pages采用从 `gh-pages` 的 `/ (root)` 发布，使用默认 `github.io` 地址。GitHub自身执行分支式Pages所需的内建部署流程；这是本项目已选择的发布方式，`.nojekyll` 不会取消平台部署。

## 在本机运行与核验

`main` 包含实际站点 `dist/`、指南、脚本和相关测试。以下命令在仓库根目录执行。

需要 Node.js 24；现有便携脚本使用内置库，无需安装 npm 外部依赖。

```sh
npm start
# 浏览 http://127.0.0.1:4173
npm run check
npm test
```

`npm run check` 检查静态结构、脚本语法、JSON、相关本地路径和文件大小；本机路径命中仍需人工复核。`npm test` 运行公开副本提供的模型、视角与限定纹理测试。它们不是素材许可、隐私清理、完整数据库一致性或历史正确性的认证，也不等于维护者完整档案的全套验收。

按实际改动补充页面核验：首次加载、相关年份前后、国家详情、来源入口、图层以及项目站点子路径。记录起点提交、实际命令、结果和未完成项；失败原因保留，不靠改旧计数或补空文件求通过。

## 一次手动发布

1. 在 `main` 的候选分支完成改动、来源审查及必要独审，保留前后值。历史争议仍按“原件 → 断言/冲突 → 阶段候选 → 独审 → 精确采用”处理。
2. 在本机运行相关检查，核对拟公开文件清单、来源定位、素材许可与已知限制。将准确的 `main` 提交和站点文件清单/SHA作为本次发布候选；之后若候选变动，按依赖重新核验。
3. 根据维护者已明确授予本轮的对话授权，提交或合并 `main`。**这一步不更新网站。** 没有发布指令时可以在此停止，保留可审查结果。
4. 按针对具体候选的发布指令准备 `gh-pages`。在干净的Git检出中运行 `node scripts/prepare-pages.mjs`，将已核验 `dist/` 的内容复制到全新本地目录（默认 `.pages-stage`），加入 `.nojekyll`，并生成绑定来源提交与文件SHA的 `publication.json`。核差异、子路径和完整性，记录原先发布提交；不得把整套工作目录复制进去。
5. 按已授权范围推送 `gh-pages`。此操作会触发平台的 Pages 部署，因此它本身就是发布动作，不是普通的候选备份。
6. 部署结束后检查实际网址、页面版本和关键资产，报告本次发布提交与实测范围。推送成功、本地检查通过或平台状态成功，都不能单独代替在线验收。需要回退时，核对上一份已验证快照并按维护者指令另行发布，保留记录。

`node scripts/prepare-pages.mjs` 只制作本地发布暂存副本，不执行 `git commit`、推送或远端配置，运行它不等于上线。准备后仍须按已授权范围进行受控分支操作和在线核验。完整研究导出、历史采用及数据库重建的一键CLI尚未提供；不要猜测旧发布器参数。

## 已知限制

首发收录1123个政治步骤、2347个公众事件和4967条研究记录。这些是收录与处理数量，不是同等数量的独立史实确证。

- 37项阶段限定继续区分分治、地方共同体、弱边界及其他具体不确定性。地方集合不等于统一国家，不虚构统一首都或国旗。
- 19处1820位置或来源冲突采用前阶段方案的一年有界续接，不证明1820整省主权，也不表示该年发生转属。原始1820政治、投影与默认显示分层保留。
- 彩色限定条纹默认关闭，可在图层中开启；关闭纹理不取消省份提示、国家详情和来源页的限定。
- 隐厦尚未纳入本轮历史重建。未收录、初始国家控制未指定、严格模式过滤与历史撤离分别解释，空白不表示无人居住。
- 确年、地方边界、身份承接和来源版本仍有未决之处。本次不认证全域历史完整、全部方法迁移或来源检索穷尽。
