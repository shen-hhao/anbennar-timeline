# community-preview-20260923

这是 `shen-hhao/anbennar-timeline` 的首个社区预览发布标识。站点地址为 [shen-hhao.github.io/anbennar-timeline](https://shen-hhao.github.io/anbennar-timeline/)。本次公开发布继承历史候选 **0.25.0**，没有将其改称新的历史内容版本。

`release.json` 记录候选标识、日期与范围；本地暂存工具生成的 `publication.json` 绑定来源提交和静态文件SHA。实际发布提交与部署时间以Git/Pages记录为准。本说明不把准备文档、本地验证或推送成功当作已经完成在线验收。

## 首发提供什么

- 1444—1820年的社区历史地图、事件、国家沿革、来源入口和相关显示工具。
- 1123个政治步骤、2347个公众事件、4967条研究记录；数量表示收录，不代表同等数量的独立史实确证。
- `main` 中的静态站点 `dist/`、公开贡献指南、本机启动/检查脚本及相关便携测试。
- 可用于阅读、来源追溯与提出修改方案的公开JSON。原有source ID、版本与来源内容哈希继续承担各自的追溯作用；公开净化后的文件校验另按发布记录解释。

完整研究原件、完整模组安装目录和SQLite数据库不分发。公开JSON仍含已采用摘录、引文和研究说明，不能视为纯原创摘要，也不是完整研究库的一键重建输入。`source-archive/...` 的含义见 [来源定位说明](SOURCE_LOCATORS.md)。

## 应当保留的限制

37项阶段限定继续区分分治、地方集合、弱边界与其他具体不确定性。19处1820有界续接仅在相应默认方案中沿用前阶段表示一年，不证明整省主权或当年转属；原始州政治、几何投影和当前显示各自保留。此前没有国家显示的地区不因此虚构前身。

彩色限定条纹默认关闭，可由图层开关启用；省份提示、国家详情、端点与连续推演页面继续展示限定。地方共同体不是统一国家；同色不是主权确证，首都定位也不自动证明完整疆域。

隐厦尚未纳入本轮历史重建。未收录、初始国家控制未指定、严格过滤与历史撤离分别解释，空白不代表无人居住。确年、身份承接、具体地方边界和来源版本仍有未决之处；本发布不认证全域历史完整、全部方法迁移或来源检索穷尽。

技术测试的覆盖、历史方案相容性与史实确定性分别报告。随公开仓库提供的测试不是维护者全部研究档案的完整回放；缺少原件时，可以提交来源线索和提案，而不必伪造重建成功。

## 发布与后续维护

采用手动推送 `gh-pages`、平台内建Pages部署的方式。`main` 更新不直接上线；站点快照为已核验 `dist/` 的内部内容置于发布分支根目录，并带 `.nojekyll`。不提供 `.github/workflows/`，不设置自定义Actions、自动合并或定时反馈任务。

`scripts/prepare-pages.mjs` 只生成本地发布暂存目录和 `publication.json`，不执行提交、推送或远端配置。实际发布与在线核验按维护者已明确的对话指令完成。

维护者在对话中发起本机反馈处理。具体历史改动仍经过来源、断言/冲突、候选、独审和精确采用；网页公开不意味着之后的每条建议都会自动成为地图。
