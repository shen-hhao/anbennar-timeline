# 公开来源定位

公开副本用 `source-archive/...` 替换维护者电脑上的绝对路径与私人目录名。这个前缀是归档定位标识，不是可点击的下载地址，也不表示原始模组、社区文档或私人档案已随网站分发。

已知模组/项目保留来源包内的相对目录和文件名；无法安全确定公共根目录时使用定位字符串哈希与文件名。定位哈希用于区分原始位置，不是原件内容哈希。原有source ID、公开链接、版本、原件SHA、行号和段落等字段分别保留。

需要复查时，先用公开URL及版本，再用相应来源包内的定位。无法取得原件可在Issue注明缺失；不要猜测维护者的本机目录，也不要把缺附件当成原文不存在。

这次公开副本仅变更7945个已逐项核验的来源定位字符串。其他JSON内容与结构保持一致，包括历史原文、政治数据、日期、身份与来源内容哈希。历史输入SHA继续说明原始输入；它不等于净化后公开JSON的文件SHA，公开文件应以对应版本的导出清单核验。

路径清理不授予素材再分发权，也不代表已经上线。当前素材范围仍按资产登记和实际发布说明判读。
