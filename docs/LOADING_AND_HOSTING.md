# 地图加载与静态托管

2026-10-03 的技术修复只改变资料传输和读取方式，不改变历史结论、地图归属、原始 JSON 或不确定性限定。

## 加载流程

- 首屏读取地图所需资料和国家沿革目录；完整沿革在打开相应国家时读取。
- `dist/data/runtime/` 是从现有公开 JSON 生成的传输副本，采用内容哈希文件名和 gzip。地图公众文案仅保留该页面使用的通知，重新索引文本池；所有事件、国家、日期订正和来源并集保留。
- 支持 Compression Streams API 的浏览器直接读取压缩资源；旧浏览器回退到普通 JSON。服务器已解压的响应也能识别。
- 成功读取的压缩资料尽量存入浏览器 Cache Storage，网络失败或存储不可用不会被误判成空资料。
- 数据请求有 20 秒无数据超时和 90 秒总超时，并自动重试一次。断流也受超时控制；失败后显示原因和重试入口。省份底图有独立超时。
- 地图程序本身未能下载时，页面在 15 秒后显示连接提示与重试按钮。
- 资料库、连续推演、参考目录及端点页面也使用同一压缩读取器。

首次地图所需 JSON 的 gzip 总大小为 4,194,996 字节，加底图 731,708 字节，共约 4.93 MB；不含 HTML、脚本、样式和后续可见旗帜。旧站以 `Accept-Encoding: gzip, br` 实测同范围响应体合计 14,160,617 字节，减少约 65%。这不是大陆各运营商的实测打开时间，也不能解决域名本身无法连接的问题。

## 本机更新

原始公开资料仍在 `dist/data/*.json`。历史采用仍遵循贡献指南；传输生成器不承担历史裁决。

```sh
npm run build:loading
npm test
npm run check
```

改动原始 JSON 后运行 `build:loading`，并把生成后的清单、gzip 和兼容副本一起提交。不要手改压缩包。生成器不修改原件，不推送或部署。`loading.test.mjs` 对原始资料、全部 1235 个国家文件、公众文案与日期限定做一致性核对，并检查重试、断流和缓存降级。

发布继续采用本机核验后手动推送 `gh-pages`；没有新增 Actions、自定义部署工作流或反馈轮询。`dist/release.json` 的 `siteRevision` 标识技术修复，历史候选版本仍为 0.25.0。

## 大陆访问与备用站

GitHub Pages 保留为现有公开地址。缩小传输量能改善弱网，但不能保证所有大陆网络都稳定连接 GitHub。

可以后续用同一份已核验静态快照建立备用站，代码和社区反馈继续在 GitHub 维护。优先试用腾讯 EdgeOne Pages / Makers 等平台的免费额度，并由不同运营商实际访问验证。可以采用手动上传，无需引入 GitHub Actions。

在 2026-10-03 查阅的平台文档中，EdgeOne Makers 免费额度的单文件上限为 25 MB、每项目最多 20,000 文件；当前仓库仍保留大于 25 MB 的原始 JSON，因此不能直接把整个 `dist/` 原封不动上传。正式使用时应另制符合限制且保留兼容读取的发布包，再验证所有页面，不能删除原件或只上传一个无法回退的半成品。

使用中国大陆节点及自定义域名，需按平台的域名备案要求处理。没有备案域名时，可以先实测其境外/香港等可用区域；访问改善应以实际网络测试为准。Cloudflare 免费全球网络不等于 Cloudflare 中国网络，后者是单独的企业服务。

平台条款、免费额度及区域可用性会变化；创建账户、购买域名、备案或开通付费服务前，应由维护者选择并核对当前账户条件。
